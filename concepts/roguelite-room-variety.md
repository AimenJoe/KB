# 로그라이트 방이 반복되게 느껴질 때

## 요약
"방이 다 비슷하다"는 대개 **모양이 아니라 방마다 할 판단이 같아서**다. 모양(지형·장식)만 바꾸면 몇 번 만에 눈이 익는다. 방마다 무엇을 먼저·어디서·어떻게 할지가 달라지게 — 편성(누구와), 싸움 종류(어떻게 끝나나), 등장(어디서 오나), 보상(왜 들어가나), 세기 곡선(언제 쉬나) — 를 바꾼다.

## 본문

### 먼저 무엇이 늘 같은지 센다
절차 생성기의 출력에서 "방마다 바뀌는 것"과 "늘 같은 것"을 나눠 적는다. 흔히 늘 같은 것:
1. **목표**: 들어서면 잠기고, 다 잡으면 열린다.
2. **등장**: 정해진 자리에서 한꺼번에 깬다 → 늘 "가운데에서 사방을 맞는" 그림.
3. **편성**: 적을 한 마리씩 따로 뽑는다 → 대부분 흔한 종 몇 마리, 먼저 칠 상대가 없다.
4. **동선의 뼈대**: 문 자리가 늘 같고 지형이 문 앞 길을 피해 놓인다.
5. **곡선과 이유**: 굴 하나 안에 세기 오르내림이 없고, 끝방 말고는 들어갈 이유(보상)가 없다.

### 고치는 순서(싼 것 → 비싼 것)
- **무리 표 + 세기 곡선(표만 고침)**: 지대마다 손으로 짠 무리 줄(꼭 나오는 앞자리 + 채우는 종). 무리마다 "먼저 풀 문제"가 하나씩 있게(뒷줄 사수를 앞줄이 막는 진지, 강공격으로 여는 방패, 회피 기술이 안 닿는 비행). 뒷줄은 **들어오는 문에서 먼 자리**부터 놓는다. 굴 안은 시작 옆 작게 → 가운데 크게 → 끝방 바로 앞 숨 돌리기 → 끝방.
- **싸움 종류**: 다 잡기 외에 물결(남은 적이 줄면 다음 무리), 매복(가운데에 와야 시작), 버티기(시간이 다 되면 끝, 남은 적은 정리). 무엇이 오는지 잠길 때 한 줄로 알리고, 남은 물결·시간은 HUD에.
- **등장 방법**: 그 자리에서 깨기 / 땅에서 솟기 / 위에서 떨어지기. 나타나는 동안은 **맞지도 때리지도 않게** — 예고 없는 피해는 억울하다.
- **곁방 보상 표지**: 옆 방의 보상을 문에 그림으로(Hades의 문). 센 방은 표지 테 색으로. 굴 안에서도 "어느 문으로"를 고르게 된다.
- **손으로 짠 방 틀**: ASCII 몇 장 + 뒤집기 ×2~4. 규칙(문 앞 길 비움·적 자리 수·문 곁 금지·바닥 이어짐)은 **시험이 틀마다 본다** — 사람이 그린 틀은 규칙을 어기기 쉽다.

## 왜?
- 사람은 같은 자극에 빨리 익숙해지지만, **결정**은 매번 새로 내야 해서 덜 지친다. 모양 변화는 결정을 바꾸지 않으면 장식이다.
- 보상이 보이면 싸움에 이유가 생기고, 같은 방도 "고른 방"이 된다. 고른 위험은 강요된 위험보다 덜 지루하다.

## 함정
- 방 수만 늘리면(넓은 굴) 반복감이 커진다 — 짜임 없이 늘린 수는 같은 판단의 반복이다.
- 버티기·물결은 처치 드롭을 늘린다. 솟아날 줄에 **끝을 두고**, 시간이 끝나 정리된 적은 아무것도 떨어뜨리지 않게.
- 손으로 짠 틀이 적 자리·문 앞 길을 막으면 절차 생성의 보장(이어짐)이 깨진다 → 틀은 연결 검사를 건너뛰지 말고 시험에 넣는다.
- 첫 방은 늘 쉬운 다 잡기로 — 새 규칙은 두 번째 방부터.
