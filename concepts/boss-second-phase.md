# 보스 2단계

## 요약
체력 구간에서 예고·걸음만 빨라지는 "깨어남"은 단계가 아니다 — 같은 싸움이 길어질 뿐이다. 2단계는 **새로 읽을 것 하나**(새 수)와 **익힌 수의 새 순서**(잇기)를 더하고, 넘어가는 순간을 **맞지 않는 짧은 숨**(전환)으로 보여 준다. 새 수가 모두 피할 수 있으면 승리 문턱은 그대로라 "어려워졌다"가 아니라 "달라졌다"가 된다 — 성공률 봇으로 잴 수 있다.

## 본문
### 전환: 하던 것을 버리고, 맞지 않고, 한 번 터진다
- 체력 반에서 **한 번**: 하던 공격·예고를 버린다(예고가 반쯤 찬 채 사라지는 것은 괜찮다 — 무릎 꿇는 몸이 더 크게 말한다).
- 2초 남짓 **맞지 않게**. 새 깃발을 타격 자리마다 넣지 말고, 이미 있는 "막기·튕김" 검사를 "전환 중이면 사방 참"으로 돌리면 튕김 소리·불똥·반동이 그대로 "지금은 안 들어간다"를 말한다. 넓은 타(내려찍기 둘레·되받아친 탄)는 피해 공용 함수에서 0, 마지막으로 체력 하한을 걸어 빠진 길을 막는다.
- 가운데쯤 **한 번 터진다**: 가까운 플레이어를 밀어낸다(피해 없음). 붙어서 치던 사람에게 "물러나서 다시 봐라"를 몸으로 준다. 흔들림·소리·핵 빛을 이 틱에 몰아준다.
- 동작은 새로 만들 필요가 없을 수 있다: 깨어남(무릎 → 섬)을 거꾸로 틀었다가 터지는 틱부터 앞으로.

### 새 수: 1단계 모양 규칙 안에서
- 예고 모양 규칙(받을 것 = 띠·부채꼴, 피할 것 = 원·고리)을 지킨다. 바라보는 쪽으로 솟는 줄 공격은 띠로 그리면 "받아치라"로 읽히니 **원을 겹쳐 줄지어** 그린다.
- 익힌 답을 비튼다: 고리는 뛰어 넘던 사람에게 "뛰어도 맞는 줄"(옆으로 비킴), 내 자리에 깔리던 원판(심기)을 보스가 쓰면 "그 자리에서 고리가 하나 더".
- 길이는 돌진처럼 벽·기둥 앞까지 — 같은 길이 계산을 쓴다(처음엔 돌기둥을 뚫고 솟았다).

### 잇기: 쉼을 하나 지운다
- 2단계에서 돌진이 끝나면 쉬지 않고 곧장 한 수(가까운 공격). 새 동작 없이 순서만 바꾼 것이라 싸고, "쉼이 없다"가 몸으로 읽힌다. 한 번만 — 다음에 새로 고를 때 풀린다.

### 재기
- 봇이 새 수도 같은 성공률로 피하게 가르친다. 안 가르치면 새 수가 "늘 맞는 수"로 재져 결과가 부풀어 보인다.
- 완벽한 봇(p = 1)이 피해 0이면 새 수는 모두 피할 수 있다. 90% 승리 문턱이 1단계와 같은 자리면 "다름"이고, 오르면 "어려움"이다 — 어느 쪽을 원하는지 먼저 정한다.

## 왜?
- 수치만 올리면 플레이어가 배운 것이 그대로 통해 단계가 느껴지지 않는다. 새 것을 읽게 해야 "바뀌었다"가 온다(2차 출처 공통).
- 전환에 맞지 않는 숨이 없으면, 마침 몰아치던 사람이 새 단계의 첫 수를 읽지도 못하고 맞는다. 숨이 길면 리듬이 끊긴다 — 1~2초 + 밀쳐냄이 "물러나서 보라"를 짧게 준다.
- 기존 튕김 검사를 재사용하는 까닭: 피드백(소리·불똥·반동)이 이미 플레이어에게 학습돼 있고, 타격 자리마다 깃발을 다는 것보다 빠진 길이 적다.

## 함정
- 전환 중 자세(포이즈) 쌓기·휘청을 막지 않으면 휘청이 전환을 덮어 쓴다.
- "반 아래" 신호(이벤트)를 시작 틱에 내던 코드가 있으면 터지는 틱으로 옮겨야 흔들림·소리가 몸과 맞는다 — 기존 시험이 "깨어난 틱 = 신호"를 보고 있었다.
- 던진 물건(종)을 보스 손에도 그리면 둘이 된다 — 손을 떠난 뒤엔 손의 부위를 크기 0으로.
- 체력 막대에 단계 눈금을 그을지는 취향(놀람 vs 대비) — 이 구현은 사장 선택으로 그리지 않았다.
