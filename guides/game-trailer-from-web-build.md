# 웹 빌드로 상점 영상 만들기

## 요약
도트 게임의 상점 영상은 **화면은 가짜 시계로 한 칸씩 찍고, 소리는 녹음하지 않고 기록해서 다시 섞는다.** 게임이 낸 효과음을 언제·무엇을·얼마나 크게 냈는지 오디오 함수에서 받아 적으면, 타격감은 게임 그대로이고 칸과 어긋나지 않는다. 음악은 장면마다 게임의 곡에서 골라 따로 깐다. 화면 글자는 상점의 기본 언어(Epic은 영어)로 찍는다.

## 본문

### 1. 화면: 가짜 시계로 칸 찍기
기본 방법은 [인디 게임 공식 페이지 가이드](indie-game-landing-page.md)의 "가짜 시계로 찍는 게임 클립"과 같다(실시간 녹화는 도트를 뭉갠다, 시계는 페이지가 뜨자마자 건다, 입력은 월드를 읽는 자동 조종). 상점 영상에서 더할 것:
- **브라우저 언어를 상점 언어로**(`newContext({ locale: 'en-US' })`) — HUD·보스 이름·알림까지 바뀐다.
- **개발용 글을 끈다**: 찍기 전용 빌드 기능(`clip`)에서 디버그 글(웨이브·처치 수 등)을 숨긴다. 운영 동작은 그대로.
- **장면은 이름으로 고른다**: 개발 메뉴 번호는 목록이 바뀌면 어긋난다. 소스의 목록에서 이름 → (탭, 자리)를 읽어 키를 누른다. 그래도 가끔 다른 장면에 들어가니 찍은 뒤 접촉 시트로 확인한다.
- **걷는 장면은 길을 정해 준다**: `키:초` 차례(예: `왼쪽:0.8, 멈춤:0.4, 위:0.5`). 시간표로 사방을 걸으면 벽에 박는다.

### 2. 소리: 오디오 함수를 감싸 기록하기
가짜 시계에서는 게임 시간이 실제 시간보다 느리게 흐르므로 소리를 녹음하면 칸과 맞지 않는다. 대신:
1. 엔진의 오디오 함수(macroquad 웹은 JS 번들의 `macroquad_audio` 플러그인)를 감싸, **소리 원본 바이트**(`audio_add_buffer`)와 **사건**(재생·크기 바꿈·멈춤, 시각 = `Date.now()` = 가짜 시계)을 남긴다. 번들을 서버에서 내줄 때 플러그인 등록 바로 뒤에 감싸는 코드를 끼운다.
2. 끝나면 사건 목록·원본·첫 칸의 시각을 파일로 꺼낸다.
3. 오프라인(파이썬 + ffmpeg 디코드)에서 다시 섞는다: 재생마다 원본을 놓고, 크기 바꿈은 계단 함수로 곱하고, 반복은 이어 붙이고, 멈춤에서 자른다. 장면을 잘라 쓸 때는 그 구간만.

### 3. 음악: 장면마다 고르고, 비율은 게임 그대로
- 기록에서 음악·환경음(반복 재생되는 긴 원본)은 빼고, 장면마다 어울리는 게임 곡을 깐다(들판 = 필드 곡, 보스 = 보스 곡, 마을 = 마을 곡). 같은 곡이 이어지는 장면은 끊지 않고, 바뀌면 0.5초 겹쳐 넘긴다. 머리가 조용한 곡은 시작 초를 옮긴다.
- 음악 크기는 **게임이 실제로 올린 값**(기록의 크기 바꿈 최댓값)을 쓰고, 다 섞은 뒤 전체만 loudnorm(-16 LUFS)으로 맞춘다 — 효과음과 음악의 비율이 게임과 같다.

### 4. 잇기와 규격
- 처음·끝 카드(타이틀 그림 + 로고, 끝에 "Out now")는 정수배로 키운 게임 그림으로.
- 화면은 nearest로 정수배(960×540 → 1920×1080), H.264 `-tune animation -crf 16`, AAC 48kHz. Epic 권장: 1920×1080 MP4, 30·60fps, ≤300MB, AAC 스테레오 48kHz.
- 같은 칸으로 **공식 페이지 클립**(소리 없음, 카드 없음, 960×540 그대로)도 뽑는다.
- 원본 영상(판마다 10MB 남짓)은 공개 레포 git에 쌓지 않는다 — 비공개 저장소의 **Release 첨부**(CI가 받는 git 내용·다른 Release 이름과 겹치지 않게).

### 5. 장면 고르기
- 자동 조종이 강해 보스가 금방 쓰러진다 → 보스 장면은 1.5~2초로 짧게 끊고, 기다리는 시간(장면이 뜨는 동안에도 싸움은 흐른다)을 줄인다. 컷씬이 있는 장면만 뒤로를 길게 눌러 건너뛴다.
- 카메라가 고정된 방(아레나)은 싸움이 구석으로 흐르면 안 보인다 → 가운데로 온 구간만 쓴다.
- 이상해 보이는 장면(시험용 보스의 체력 흐름 등)은 개발용 장면이라 그렇다 — 실제 게임과 같은 장면으로 바꾼다.
- 찍은 칸은 1초(또는 0.5초) 간격 접촉 시트로 모두 본다: 메뉴·검은 화면·다른 장면·안내 글을 거른다.

## 왜?
- **가짜 시계**: 실시간 녹화는 칸 간격이 고르지 않고 압축이 도트를 뭉갠다. 시계를 직접 흘리면 30fps 무손실 칸이 나온다.
- **소리를 기록으로**: 시계를 멈췄다 흘리는 동안 실제 소리는 실제 시간에 나서 칸과 맞을 수 없다. 기록해 다시 섞으면 칸과 소리의 시각이 같은 시계(가짜 시계)에서 나와 정확히 맞고, 타격음·크기·겹침이 게임이 낸 그대로라 "타격감과 박진감"이 남는다.
- **음악을 따로**: 장면을 잘라 이으면 게임 속 곡이 장면마다 처음부터(크기 0에서 서서히) 다시 시작해 끊긴다. 곡은 영상 단위로 이어 깔아야 흐름이 산다.
- **영어 화면**: 상점의 기본 페이지는 그 상점의 기본 언어로 읽혀야 한다. Epic은 그림 속 글까지 본다.

## 함정
- 감싸는 코드를 번들 끝에 붙이면 앞선 스크립트 오류에 막혀 돌지 않는다 — 등록 바로 뒤에 끼운다.
- 소리 시각과 칸 시각의 한 칸 어긋남(칸 n = 시계 (n+1)/fps 뒤).
- 장면을 자를 때, 구간 앞에서 시작해 구간 안까지 울리는 소리의 앞부분을 자르는 셈을 틀리기 쉽다(음수 인덱스).
- 소리를 사람 귀로 듣지 못하는 자동 환경에서는 파형 그림·구간 크기로 조용한 구간(곡 머리)과 넘침을 확인하고, 크기 비율은 사람이 들어 본다.
- 일부 장면이 월드만 검게 찍히는 일이 있다 — 다시 찍으면 될 때도 있고, 다른 장면으로 바꿔야 할 때도 있다.
