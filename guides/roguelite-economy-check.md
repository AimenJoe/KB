# 로그라이트 메타 재화 점검

## 요약
메타 재화(런에서 줍고 런 밖에서 쓰는 것)는 **런 하나의 벌이를 진짜 생성기로 재고**, 모든 쓸 곳을 **"다 사기까지 몇 런"**으로 바꿔 보면
검증된다. 쓸 곳은 **한 번 사면 끝**과 **런마다·꾸밀 때마다 쓰는 것**으로 나눠, 후반에 남는 양을 셈한다. 한 번 사면 끝인 쓸 곳은 아무리 늘려도
남는 양을 못 빨아들인다 — 끝없는 쓸 곳이 하나는 있어야 한다.

## 본문

### 1. 재화마다 들어오는 곳·나가는 곳 표
- 재화마다(예: 반딧불 = 영구 성장, 런 씨앗 = 런 안 가게, 마을 씨앗 = 허브) 들어오는 곳(처치·상자·방 보상·부술 것·끝방·숨은 자리·저널)과
  나가는 곳(재주 칸·이야기·꾸미기·짐·텃밭)을 **값·확률·한 번인지 런마다인지·파일 자리**까지 적는다.
- 런 끝 바꾸기(남은 런 씨앗 → 허브 씨앗), 배수(난이도 단마다 ×1.15), 한도(가방 상한)처럼 **재화 사이를 오가는 길**도 적는다 — 불어나는 고리
  (A → B → A가 1보다 크게)가 없는지 본다(예: 허브 6 → 런 5, 런 끝에 남으면 허브 1:1 → 한 바퀴에 1 잃음, 고리 없음).

### 2. 런 하나의 벌이 = 진짜 생성기로 기대값
- 행동 하나의 벌이 = Σ(값 × 확률). 이것을 **게임의 실제 지도·방·적 생성기**를 시드 수백 개로 돌려 더한다(무시 시험 하나, `--ignored`).
  손 계산은 방 수·적 수·갈래 확률이 얽혀 틀리기 쉽다.
- 평균만 보지 말고 **분포**(p10·중앙·p90)와 **길(층)마다** 값을 낸다 — 첫 길에서 쓰러진 사람의 벌이가 실제 초반 속도다.
- 가정은 적어 둔다: 버티기 방에서 몇 %를 잡나, 갈림길은 어떻게 고르나, 허브에서 바로 내려가면 건너뛰는 쉼터가 있나.

### 3. 쓸 곳을 런 수로
| 쓸 곳 | 값 | 런 수(배수 단 0 / 중간 / 끝) |
|---|---|---|
| 영구 성장 한 칸 | 최소~최대 | 한 칸 ≈ 0.4~1.7런이면 "런마다 뭔가 산다" |
| 한 캐릭터 다 | 합 | |
| 전부 − 한 번 받는 보상(저널) | 합 | → 시간(런 길이 × 런 수) |
- 이 표를 사람이 보고 "이 길이가 맞나"를 정한다(정답이 없는 수치다). 줄이는 손잡이는 값 배수 한 곳에 둔다.

### 4. 후반 남는 양
- 런마다 들어오는 양(쓰는 습관별: 아끼는 사람·보통·다 사는 사람) − 런마다 쓰는 곳의 최대 × 다 사기까지 런 수 + 한 번 받는 것 − 한 번 쓰는 것.
- 잘하는 사람은 소모품(회복·짐)을 덜 산다 → 런마다 쓰는 곳이 줄고 남는 양이 는다. 이 사람 기준으로 본다.
- 남는 것이 힘을 사지 않는다면 해롭지는 않다. 다만 "쓸 곳 없이 숫자만 는다"는 느낌이 남는다.

### 5. 끝없는 쓸 곳
- 한 번 사면 끝인 쓸 곳(자리 더 늘리기)은 남는 양의 몇 %밖에 못 빨아들인다(예: 1,900 중 120).
- **돌려 바꾸기**: 꾸밀 자리를 차례로 채우고, 다 차면 가장 오래된 자리부터 새것으로 바뀐다. 고르는 창 없이 끝이 없고, 지도는 더 붐비지 않고,
  허브가 손으로 바뀌어 보인다. 기록은 "지금껏 놓은 수(다음 자리 = 수 % 자리 수)" + 자리마다 무엇.
- 런마다 쓰는 것(다음 런 짐)은 한도를 두고, 한도 밖 하나(텃밭에서 기른 것)는 기다림(런 둘)으로 값을 낸다.

## 왜?
- 메타 재화의 목적은 "모은 이유"와 "다음 런을 할 까닭"이다. 런 수 표가 있어야 그 목적이 몇 시간짜리 약속인지 보인다.
- 벌이는 콘텐츠를 더할 때마다 바뀐다(방이 넓어지고, 상자·방 보상이 생긴다). 시험으로 두지 않으면 문서의 값은 금방 낡는다 — 실제로 세 번
  늘어난 벌이를 주석은 첫 값 그대로 말하고 있었다.
- 쓸 곳이 "한 번 사면 끝"뿐이면 다 산 뒤 재화가 의미를 잃는다. 끝없는 쓸 곳은 힘이 아닌 것(꾸미기·이야기)이어야 난이도를 흔들지 않는다.

## 함정
- **재는 시험이 들어오는 곳을 빼먹는다**: 나중에 생긴 보상(상자 재화·방 보상·뒤 무리)을 셈에 안 넣으면 벌이가 30%쯤 낮게 나온다. 새 보상을
  넣을 때 재는 시험도 같이 고친다.
- **건너뛰는 자리**: 허브에서 첫 쉼터를 지나쳐 내려가면 그 쉼터의 가게·숨은 자리는 런마다 셈에서 빠진다.
- **넘치면 조용히 사라지는 것**: "한도 밖으로 하나 더" 주는 보상이 가방 상한에 잘리면 사라진다. 넘친 것은 다음으로 넘긴다.
- **기록 키를 바꾸지 않는다**: 쓸 곳의 규칙을 바꿀 때(자리 수만 → 자리마다 종류) 옛 기록을 읽는 길을 둔다(옛 수만큼 기본 종류로 읽기).
