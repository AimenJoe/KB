# sprite-gen — 이미지 모델 스프라이트 파이프라인

## 요약
[aldegad/sprite-gen](https://github.com/aldegad/sprite-gen)은 Codex·Claude 스킬 + Python CLI(Apache-2.0)다. 기본 그림 한 장 →
동작 줄을 한 줄씩 생성(GPT 이미지 또는 Grok) → 크로마 지우기 → 격자 맞추기 → 아틀라스 + `manifest.json`(칸 사각형·fps)으로 굽는다.
정지 그림을 Grok Imagine 영상으로 움직여 투명 루프를 자르는 길도 있다. 도구를 안 쓰더라도 **문서에 적힌 규칙**이 쓸 만하다:
바탕 크로마는 대상 색에서 먼 쪽으로, 모델이 칠한 바탕색은 테두리에서 잰다, 격자 위상은 실측 채점으로, 픽셀 밀도는 참고 그림이 정한다,
숨쉬기는 목 위를 바이트째 고정한다.

## 무엇이 들어 있나
| 묶음 | 하는 일 |
|---|---|
| A 아틀라스 줄 | `prepare` → `gen-set`(줄 넷씩) → `extract`(크로마 → 투명 칸) → `compose-atlas`, 고르는 웹 화면(큐레이션)은 선택 |
| B 영상 → 루프 | 정지 그림 → Grok Imagine 클립 → 칸 → 이음매 없는 투명 루프. 걷기는 발이 엇갈리는 순간을 세어 두 걸음 한 바퀴로 자른다. 튄 칸은 RIFE 보간 |
| C 유틸 | `cutout`(단색 바탕 → 투명), `slice-sheet`(격자 시트 → 칸), `unpack-atlas` |
| D 후처리 | 팔레트 바꾸기(같은 입력 = 같은 바이트), Aseprite·Phaser·Flame 내보내기 |
| E 에셋 도구 | 반복 바탕 타일, 발 앵커에서 그림자, 움직임·접지 측정 |
- 필요한 것: `codex`(ChatGPT 로그인) 또는 Grok, `ffmpeg`·`img2webp`·`node`, 선택으로 RIFE(설치 파일 830MB).
- AI는 생성 한 곳에서만, 나머지(추출·격자·팔레트·굽기)는 결정론 코드 — 같은 입력이면 같은 출력.

## 규칙 (문서에서)
- **크로마 바탕은 대상의 주된 색에서 먼 것**: 분홍·보라·진빨강(머리·옷) 대상은 **초록** 바탕, 초록·청록 대상은 마젠타, 파랑은 시안·파랑 바탕을 피한다.
  마젠타를 기본으로 박지 않는다. 지우기는 키 색 둘레의 거리 공이라, 그 안에 든 대상 색은 어디 있든 지워진다.
- **모델은 키 색을 순색으로 칠하지 않는다**: `#00FF00`을 (8,162,24)처럼 어둡게, Grok은 `#FF00FF`를 (216,46,147)로 칠했다 —
  순색 둘레만 지우면 바탕이 남는다. 평평한 테두리에서 실제로 칠한 바탕색을 재서 그것도 지운다.
  대상 안쪽의 같은 계열 색(진분홍·보라)은 바탕과 이어져 있지 않으면 남긴다.
- **가장자리는 벗기지 말고 풀어낸다(unmix)**: 일러스트는 키와 섞인 가장자리를 "키 빠진 색 + 부분 투명"으로 되돌려 머리카락·가는 선을 살린다. 도트는 투명을 0/1로.
- **격자 위상은 실측으로 고른다**: 블록 크기(피치)가 맞아도 위상이 틀리면 격자가 블록을 반으로 가른다. 가장자리 분포로 얻은
  근사 위상은 참값에서 피치의 절반까지 밀렸고(눈 4줄이 3줄로 합쳐짐), 후보 위상마다 칸 안 균일도를 채점해 고르니 68칸 중 15칸이 ±1칸 바로잡혔다.
- **픽셀 밀도는 프롬프트가 아니라 참고 그림이 정한다**: 생성 크기는 1024px 급으로 고정이고 "TRUE N×N grid" 글만으로는 밀도가 안 잠긴다.
  모델은 붙인 참고 그림의 블록 굵기를 따른다 → 참고 그림은 **목표 해상도의 진짜 도트를 nearest로 키운 것**. 고해상 가짜 도트를 붙이면 그 밀도를 따라가 줄일 때 뭉개진다.
  체형·외곽선 굵기를 글로 다시 쓰지 않는다 — 글이 참고 그림과 다퉈 생김새가 돌아간다.
- **숨쉬기(정지 자세를 살아 있게)**: 정수 줄·칸 단위로만 늘이고 줄인다(1px 외곽선 유지). **강체 경계는 가슴이 아니라 목**(형태상 병목이라 안정적),
  목이 없는 덩어리는 눈 한 쌍을 찾아 그 아래로 — 머리는 모든 칸에서 바이트째 같다. 짧은 루프에 숨을 여러 번 넣으면 1px 위상이 칸마다 뒤집혀 떨림으로 읽힌다
  (숨 한 번에 6칸 이상).
- **좌우가 다른 소품**: 오른쪽을 보는 그림을 뒤집으면 손목시계·핀이 반대 손으로 간다 — 왼쪽은 따로 그리거나(값이 더 든다) 뒤집기를 받아들인다.

## 왜?
- 이미지 모델의 "스프라이트 시트"는 칸마다 얼굴이 바뀌고, 바탕이 안 지워지고, 격자에서 떠돈다. 생성은 사람이 고르는 한 단계로 두고,
  나머지를 재현 가능한 코드로 두면 고칠 때 되돌릴 수 있다.
- 지우기·격자 맞추기의 실패는 대개 "가정한 값"(순색 키, 근사 위상)에서 온다 — 그림에서 **실제로 잰 값**으로 바꾸는 것이 이 문서들의 공통 처방이다.

## 함정
- GPT 이미지·Grok 전용이다. 다른 모델(예: 나노바나나)로 그린 원본의 그림체와 섞으면 어긋날 수 있다 — 규칙만 빌리고 생성은 쓰던 모델로.
- 참고 그림 규칙: 유료 팩 그림을 생성 참고로 넣으면 팩 라이선스(AI 학습·참조 금지)에 걸릴 수 있다. 참고 그림은 직접 만든 원본만.
- 문서의 수치는 만든 사람 회귀 기록이다(우리가 잰 값이 아니다).
